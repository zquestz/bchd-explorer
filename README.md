# BCHD Explorer

Simple block explorer for the BCHD gRPC API with SLP and Cash Tokens support.

## Project setup
```
npm install
```

### Runs a development server with hot reload
```
npm run dev
```

### Builds for production into `dist/`
```
npm run build
```

### Serves the production build locally
```
npm run preview
```

### Lints files
```
npm run lint
```

### Runs tests
```
npm test
```
